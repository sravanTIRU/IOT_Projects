## Programs

1. **UDP Echo Communication Between Two Nodes** — Simulates UDP client-server communication with an echo server.
2. **Bandwidth, Delay and Throughput Analysis Using FlowMonitor** — Measures packet statistics, average delay, and throughput.
3. **Three-Node Network Communication Using Routing** — Sends UDP packets from a source through a router to a destination.
4. **IoT Gateway Communication Using NS-3** — Simulates four IoT nodes sending packets to a central gateway.
5. **Performance Comparison of TCP and UDP Protocols** — Compares received data for TCP and UDP traffic.
6. **Network Congestion and Throughput Analysis** — Simulates UDP traffic over a limited-bandwidth link and measures received throughput.

## Requirements

- NS-3 installed and configured
- C++ compiler supported by your NS-3 version

## Running

Place the source files in the appropriate NS-3 directory (for example, `scratch`) and run each program using the command supported by your NS-3 version.
